 # richardtaylordawson.com

> My personal website & resume showcasing my experience, projects, and more. Built using TailwindUI, React, NextJS, and agentic AI.

## Run Project

```shell
$ yarn install
$ yarn dev
```

## Apps

- `apps/richardtaylordawson.com` - current production site
- `apps/v1` - first historical site snapshot from `history/v1`
- `apps/v2` - May 30, 2026 site snapshot from the repo history
