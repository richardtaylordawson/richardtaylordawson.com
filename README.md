 # richardtaylordawson.com

> My personal website & resume showcasing my experience and projects. Built using TailwindUI, React, and NextJS.

## Run Project

```shell
$ yarn install
$ yarn develop
```

## Apps

- `apps/richardtaylordawson.com` - current production site
- `apps/v1` - first historical site snapshot from `history/v1`
- `apps/v2` - second historical site snapshot from `history/v2/next-pages-site`

The `history/` directory remains as an archive/reference copy.
